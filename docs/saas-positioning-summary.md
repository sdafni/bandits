# SafeKey SaaS Positioning Summary

## Category
Rental trust infrastructure for the Greek market — combining tenant screening, structured review workflows, and protection-ready eligibility outputs.

## Target customers (current → V2)
| Segment | Current | V2 |
|---------|---------|-----|
| Individual landlords | Primary | Supported |
| Property managers | Secondary | Multi-property workspaces |
| Agencies | Partner conversations | White-label upload + portfolio analytics |
| Insurance / protection partners | Distribution narrative | API + underwriting handoff |

## Core value proposition
**For landlords and property operators** who need defensible rental decisions, SafeKey is the workflow layer that turns applicant documents into a structured risk score, recommendation, and protection eligibility outcome — without email chaos or opaque judgment calls.

## Differentiation
1. **Greece-first workflow** — Tenant Passport Greece module aligned to local rental evidence expectations.
2. **Operational credibility** — Case states, analyst review, audit-friendly timelines.
3. **Protection bridge** — Screening outputs connect to deposit/rent/full-shield packaging narratives.
4. **Expat-ready story** — Standardized evidence pack for mixed local and relocating applicants.

## Product layers
1. Screening workflow (cases, uploads, review)
2. AI recommendation output (approve / conditional / decline)
3. Billing (subscription + per-case screening)
4. Protection eligibility (partner-ready packaging)

## Investor demo vs production
| Mode | Purpose |
|------|---------|
| **Investor demo** | Curated in-memory portfolio merged into dashboard/admin; `/demo` guided hub |
| **Production** | Live Supabase cases, Stripe billing, webhook-synced entitlements |

## Messaging pillars
- **Trust** — Scoped access, structured review, clear outcomes.
- **Clarity** — Pipeline states and readable recommendations.
- **Professionalism** — Legal-tech aesthetic, minimal UI, enterprise calm.
- **Operational credibility** — Analyst desk, billing gates, protection signals.
