# SafeKey Brand Assets

This folder contains the reusable SafeKey visual identity pack for the MVP.

## Structure

- `icon/`
  - app icon and compact brand mark
- `logo/`
  - primary SafeKey horizontal logo
- `full-lockup/`
  - SafeKey + Tenant Passport Greece combined lockup
- `backgrounds/`
  - reusable premium background artwork
- `ui-visuals/`
  - polished product illustrations and visual placeholders

## Current assets

- `icon/safekey-icon.png` - final production icon
- `logo/safekey-logo.PNG` - final production horizontal logo
- `full-lockup/safekey-tenant-passport-greece-lockup.svg`
- `backgrounds/safekey-hero-grid.svg`
- `ui-visuals/tenant-verification-visual.svg`
- `ui-visuals/secure-upload-visual.svg`
- `ui-visuals/ai-risk-report-visual.svg`
- `ui-visuals/landlord-dashboard-visual.svg`

## Usage

- Use `icon/safekey-icon.png` for favicon, compact UI marks, and upload-screen branding.
- Use `logo/safekey-logo.PNG` as the primary production header/logo asset across the MVP.
